Имя директории во вкладке iTerm2
================================

Когда открыто много вкладок, удобно, чтобы на каждой было видно имя текущей директории (только последнюю компоненту пути, например `CookBook`, а не `~/Documents/CookBook`).

Настройка zsh
-------------

Добавить в `~/.zshrc`:

```zsh
autoload -Uz add-zsh-hook

_set_tab_title() {
	print -Pn "\e]1;%1~\a"
}

add-zsh-hook precmd _set_tab_title
```

Что здесь что:

- `\e]1;...\a` — escape-последовательность OSC 1, задаёт заголовок вкладки (OSC 2 задаёт заголовок окна);
- `%1~` — последняя компонента пути (в домашней директории будет `~`); если нужно две последние компоненты, то `%2~`;
- `precmd` срабатывает перед каждым приглашением, поэтому заголовок восстанавливается и после программ, которые его меняют (`vim`, `ssh` и т.п.);
- `add-zsh-hook` добавляет функцию к хуку, не затирая другие `precmd`.

Настройка iTerm2
----------------

В Settings → Profiles → (профиль):

1. General → Title: должен быть отмечен Session Name (escape-последовательность меняет именно его).
2. Terminal: включено "Applications in terminal may change the title" (по умолчанию включено).

Oh My Zsh
---------

Oh My Zsh сам выставляет заголовки и может перебивать этот хук. Чтобы отключить, в `~/.zshrc` до строчки `source $ZSH/oh-my-zsh.sh` добавить:

```zsh
DISABLE_AUTO_TITLE="true"
```

Применить
---------

Работает в новых вкладках; в уже открытых выполнить `source ~/.zshrc`.
