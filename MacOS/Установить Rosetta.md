Установить Rosetta
==================

Rosetta 2 нужна на Mac с Apple Silicon, чтобы запускать приложения, скомпилированные только для Intel (x86_64).

Отдельного переключателя «Rosetta для всех приложений» нет. Rosetta достаточно установить один раз, после этого macOS сама запускает через неё все Intel-only приложения.

Проверить, установлена ли
-------------------------

```shell
arch -x86_64 /usr/bin/true && echo OK
```

Если Rosetta нет, будет ошибка `Bad CPU type in executable`.

Установить
----------

```shell
sudo softwareupdate --install-rosetta --agree-to-license
```

Другой способ: запустить любое Intel-приложение, macOS сама предложит установить Rosetta.

Флажок "Open using Rosetta"
---------------------------

Finder → Get Info (⌘I) → "Open using Rosetta".

Нужен только для universal-приложений (в которых есть код и для Intel, и для Apple Silicon): флажок заставляет запускать Intel-версию. Например, когда нужен старый плагин, который есть только для Intel. Для Intel-only приложений он не нужен.

Важно
-----

Apple объявила, что macOS 27 — последняя версия с полной поддержкой Rosetta. Дальше Rosetta останется только для ограниченного набора старых игр. Поэтому для важных приложений лучше искать версии для Apple Silicon.
